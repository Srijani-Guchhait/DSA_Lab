The repository is designed to bridge theoretical computer science concepts with efficient, functional code implementations for academic study and practical reference.

## ▶️ How to Run

1. Clone this repository:

```bash
git clone https://github.com/Srijani-Guchhait/DSA_Lab
```

2. Open the project folder in VS Code.

3. Compile a C program:

```bash
gcc filename.c -o program
```

4. Run the program:

**Windows:**

```bash
program.exe
```

**Linux/macOS:**

```bash
./program
```
